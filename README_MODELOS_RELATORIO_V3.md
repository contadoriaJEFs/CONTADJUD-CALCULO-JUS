# ContadJus 2.0A — Modelos de Relatório v3

Alterações desta versão:
- Mantido o modelo atual sem alteração de identidade visual.
- Mantido o modelo alternativo Cálculo Jus, com terracota predominante e barra vertical no título.
- No modelo Cálculo Jus, o texto anteriormente em navy passa a usar preto/grafite opaco, preservando o terracota como cor de destaque.
- Quando o tipo de requisitório é exclusivamente Precatório, a seção Resultado da Renúncia não é incluída em nenhum modelo de relatório.
- Quando o tipo é exclusivamente Precatório, o Resultado do Requisitório não exibe Salário mínimo nem Limite de 60 salários mínimos; o quadro passa a apresentar apenas Data-base e Tipo de requisitório.
- Quando o tipo é RPV ou RPV/Precatório, a apresentação existente desses dados permanece.
- Nenhum cálculo, fórmula ou motor de cálculo foi alterado.
